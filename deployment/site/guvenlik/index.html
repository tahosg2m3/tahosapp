Defense in depth

Security is an ongoing process, not a single setting.

tahosapp protects accounts, servers, files, and real-time connections through multiple layers. No online service can promise perfect security, so updates, monitoring, and responsible disclosure work together.

Account and session security

  • Email verification during registration and email-based second verification during login
  • Passwords are never stored as plain text and are hashed with Argon2id
  • SHA-256 and HMAC-SHA-256 are used for verification codes, high-entropy access tokens, and integrity checks—not password storage
  • Session tokens, token versioning, and session invalidation
  • Rate limiting on authentication and sensitive endpoints
  • Server-side role and permission checks that prevent unauthorized actions

Protection of stored data

Application state can be encrypted on server storage with AES-256-GCM, with the encryption key stored separately from the database. Passwords are irreversibly hashed with Argon2id.

Encrypted storage is not end-to-end encryption. The server must process some content to operate the service, deliver messages, and support moderation.

Network, voice, and video

Web and API traffic uses HTTPS/TLS. Voice, camera, and screen sharing use secure WebRTC transport. Traffic may be relayed through TURN when direct connectivity fails; call content is not recorded by the server during normal operation.

  • Cloudflare network and application protection
  • Origin restrictions, CORS, CSP, and security headers
  • Separate hostnames for API, web, and voice services
  • Request-size and connection-rate limits

File and content security

Uploads are checked using allowed type, size, file signature, and safe filename rules rather than trusting extensions alone. User content may still be harmful; do not run files from people you do not trust.

What users can do

  • Use a long, unique password and do not reuse it elsewhere.
  • Never share verification codes, passwords, or session tokens.
  • Keep the app updated and download it only from tahosapp.com.tr.
  • Verify suspicious links and files before opening them.
  • Change your password and contact support if you see unexpected account activity.

Report a vulnerability

If you discover a vulnerability, use GitHub's private security reporting channel instead of posting a public issue or social-media message. Include the affected area, reproduction steps, possible impact, and a safe proof if available. Do not access real user data, alter data, or disrupt the service.

Transparent limits

tahosapp is an independently developed, evolving project. Security controls reduce risk but cannot guarantee flawless or uninterrupted operation or prevention of every attack. Install critical updates promptly.
