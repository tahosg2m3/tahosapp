Frequently asked questions

What to know before you begin.

What is tahosapp?

tahosapp is an independent platform for messaging, voice and video calls, screen sharing, direct messages, and community management.

Is tahosapp free?

Yes. Current features including messaging, 4K streaming, GIF avatars, custom emoji and stickers, themes, profile effects, avatar decorations, and server profiles are free.

Do I need to install the app?

No. Use it in a browser or install the Windows desktop app. Some desktop features are available only in the installed application.

Do Spotify invitations require Premium?

No. Every user can share a Spotify track link and open it in their own Spotify account. Only automatic Listen Along playback requires an eligible Premium integration.

Are voice and video recorded?

Voice and video are sent between participants through WebRTC and may use a TURN relay when necessary. Call content is not recorded by the server during normal operation.

How is my account protected?

Security layers include email verification, login codes, Argon2id password hashing, session protection, rate limits, and encrypted application data.
